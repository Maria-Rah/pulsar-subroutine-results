# Data

| Folder | Content |
|---|---|
| `run1/` | Host diagnostics summaries (`GLOBAL`, `SEV`, `BEV` guides) of Run 1 (N = 50 000, 0–9.14 Myr) and, in `realisation_v2/`, of its second realisation (500 binaries, 0–9.36 Myr). No NS forms, so there are no `pulsar.55` records. |
| `run2/` | `pulsar.55_*.dat` of Run 2 and the host diagnostics summaries of the 5000-star model shared by Runs 2–4. |
| `run3/` | `pulsar.55_*.dat` of Run 3. |
| `run4/` | `pulsar.55_*.dat` of Run 4, the basis of Sect. 4 of the paper, and `run4_records.csv`, the 286 distinct records with a header line. |

The files cover 15–22 and 26–27 Myr; files for 23–25 Myr are not in the archive. The column format is described
in [`../docs/PULSAR55_FORMAT.md`](../docs/PULSAR55_FORMAT.md).
